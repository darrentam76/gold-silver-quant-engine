## System Constraints & Market Microstructure Rules

1. **Intraday Real Rate Equivalence**:
   - Breakeven inflation lacks a high-frequency 1-minute feed. The injected breakeven is a daily constant anchor.
   - Intraday 1-minute real yield variance ($\Delta \text{Real 10Y}$) is mathematically identical to 1-minute nominal yield variance ($\Delta \text{TNX}$). Signals MUST be documented as a Nominal Proxy for Intraday Real Rate Variance.
2. **Futures-Primary Routing & Basis Continuity**:
   - To prevent upstream 404/delisting errors inherent to Yahoo FX spot tickers (`XAUUSD=X`), futures (`GC=F`, `SI=F`) serve as the primary execution and pricing feeds. 
   - When spot feeds are available, a rolling 30-bar basis mean is applied for spot adjustment; otherwise, primary futures are cleanly mapped into internal series.
3. **Off-Session Rate Feed Handling**:
   - CBOE rates tickers (`^TNX`, `^TYX`, `^IRX`) update strictly during US cash session hours. Non-US session ticks deplete the 3-bar forward-fill budget, marking off-hours data as `STALE`.
4. **Static Type Safety & Null Guardrails**:
   - Upstream API responses MUST be checked for `None` or `.empty` attributes prior to accessing index properties, satisfying static type checkers (Pyright/Pylance) and guaranteeing pipeline fallback protection.
5. **Out-of-Scope Asset Rejection**:
   - System is strictly limited to precious metals, yield curve metrics, and real rates. Requests for individual equities or crypto signals MUST be rejected cleanly at the interface layer.

### Step 2: Resampling & Joint-Quality Gating
- Resample all timestamp indices to a strict 1-minute UTC grid (`resample("1min").asfreq()`).
- Forward-fill (`ffill`) missing price ticks up to a maximum budget of **3 consecutive bars**.
- **Joint Quality Gating**:
  - If EITHER Gold OR Silver exceeds the 3-bar forward-fill limit, mark the bar's quality as `STALE`.
  - Compute the Gold/Silver Ratio ($\text{GSR}_t$) ONLY after basis adjustment and ONLY on valid bars:
    $$\text{GSR}_t = \begin{cases} \frac{\text{Gold}_t}{\text{Silver}_t} & \text{if Quality} = \text{OK} \\ \text{NaN} & \text{if Quality} = \text{STALE} \end{cases}$$
  - *Constraint*: Joint gating prevents synthetic ratio spikes caused by single-leg failovers or asymmetric feed drops.

### Step 3: Yield Curve & Real Rates Construction
- **10-Year Real Rate Proxy**: $\text{Real\_Yield\_10Y}_t = \text{TNX}_t - \text{breakeven\_10y}$
- **10Y3M Curve Slope**: $\text{Slope\_10Y3M}_t = \text{TNX}_t - \text{IRX}_t$
- **30Y10Y Curve Slope**: $\text{Slope\_30Y10Y}_t = \text{TYX}_t - \text{TNX}_t$
- **Disclosure Obligation**: Expose static string metadata:
  `"proxy_disclosure": "Intraday 1-minute real rate changes use 10Y nominal yield variance anchored against daily breakeven."`

### Step 4: Mathematical Signal Engine (Dual Z-Score Modality)
All rolling calculations MUST use a 60-bar window (`period="1d"`) or 1,440-bar window (`period="7d"`) with strict $t-1$ historical lookback (zero look-ahead bias).

1. **Macro Velocity Signals (CHANGES / Shocks)**:
   - Compute 1-minute differences for Real Yields and Gold:
     $$\Delta \text{Rate}_t = \text{Real\_Yield}_t - \text{Real\_Yield}_{t-1}, \quad \Delta \text{Gold}_t = \text{Gold}_t - \text{Gold}_{t-1}$$
   - Calculate rolling Z-scores on changes (`rr_z`, `gold_z`):
     $$Z_{\Delta, t} = \frac{\Delta X_t - \mu_{t-1}(\Delta X)}{\sigma_{t-1}(\Delta X)}$$

2. **Stat-Arb Relative Value Signal (LEVELS / Stretch)**:
   - Calculate rolling Z-score directly on raw ratio **LEVELS** (`gsr_z`):
     $$\text{gsr\_z}_t = \frac{\text{GSR}_t - \mu_{t-1}(\text{GSR})}{\sigma_{t-1}(\text{GSR})}$$
   - *Constraint*: Do NOT compute `gsr_z` on changes; relative-value statistical arbitrage requires evaluating ratio level stretch against its rolling mean.

3. **Post-STALE Recovery Isolation**:
   - For any bar where `quality == STALE` OR the previous bar was `STALE` (`is_stale.shift(1)`), force `rr_z = NaN`, `gold_z = NaN`, `gsr_z = NaN`.
   - *Constraint*: Prevents price gaps or step-functions following data outages from triggering false directional shocks.

### Step 5: Dual State Machines with Hysteresis

1. **Macro Regime State Machine** (`z_threshold = ±1.5`, 5-bar exit streak):
   - `DECOUPLING_ALERT`: $|rr\_z| \ge 1.5$ AND $|gold\_z| \ge 1.5$ AND $\text{sign}(rr\_z) == \text{sign}(gold\_z)$.
   - `BEARISH_PRESSURE`: $rr\_z \ge +1.5$.
   - `BULLISH_CATALYST`: $rr\_z \le -1.5$.
   - `NEUTRAL`: Default state.
   - **Hysteresis**: When exiting an active alert, hold the previous state for **5 consecutive calm bars** before reverting to `NEUTRAL`.

2. **Stat-Arb Signal Flag Machine** (`arb_threshold = ±2.0`, 3-bar exit streak):
   - `GSR_LONG_SILVER_SHORT_GOLD`: $gsr\_z \ge +2.0$ (Ratio overextended upward; Silver cheap, Gold rich).
   - `GSR_LONG_GOLD_SHORT_SILVER`: $gsr\_z \le -2.0$ (Ratio overextended downward; Gold cheap, Silver rich).
   - `NONE`: Default state.
   - **Hysteresis**: Hold active arbitrage flag for **3 consecutive calm bars** to prevent boundary flickering at $\pm 2.0\sigma$.
